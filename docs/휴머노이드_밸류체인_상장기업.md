# 휴머노이드 밸류체인별 투자 가능 상장기업 (비중국, 2026.9 기준)

## 선정 기준
- 상장사만 포함했다. 대상 시장은 한국(유가증권·코스닥), 미국, 일본, 유럽이다. 중국 본토·홍콩 상장사와 중국 기업은 제외했다.
- 휴머노이드 관련 사업이 공시, 회사 발표, 언론 보도로 확인되는 기업만 올렸다. 로봇 전반의 테마주는 뺐다.
- 관여도 표기
  - ● 확인: 공급, 수주, 양산, 도입이 확인됨
  - ◐ 진입 중: 제품 개발, 샘플, 협의 단계
  - ○ 간접: 범용 부품이라 휴머노이드 기여분을 따로 떼어 보기 어려움

## 3. 제외했거나 상장 전인 곳(관찰 대상)
- 보스턴다이나믹스: 현대차그룹 100% 자회사다. 업계는 미국 상장을 2028년 전후로 추정한다(공식 발표 없음).
- Agility Robotics: 2026.6 CCXI와 합병을 발표했다. 연내 종료 예정이며 종목코드는 AGLT가 될 예정이다.
- 에이딘로보틱스: 힘·토크 센서 업체로, 2027년 코스닥 상장을 추진 중이다.
- 비상장: 피규어AI, 앱트로닉, 1X, 피지컬 인텔리전스, 스위스 GSA(롤러 스크류), 리벨리온·퓨리오사AI.
- 중국 관련 제외: 유니트리, 애지봇, 유비테크, 리더드라이브, 투푸, 싼화, JL Mag 등.
