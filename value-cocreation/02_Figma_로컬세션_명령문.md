# 로컬 세션용 Figma 작업 명령문

## 사전 준비
1. 이 브랜치(`claude/laughing-planck-usfcxd`)를 로컬로 받는다.
   ```
   git fetch origin claude/laughing-planck-usfcxd
   git checkout claude/laughing-planck-usfcxd
   ```
2. 로컬 Claude Code에서 Figma MCP가 연결되어 있는지 확인한다(`/mcp`에서 figma가 connected인지).
3. `03_제출전_확인목록.md`의 `[원문 확인]` 항목을 먼저 확인해서 원고를 고쳐 두면 Figma에서 다시 손댈 일이 줄어든다.
4. 학번, 학과, 이름을 준비한다.

## 붙여 넣을 명령문 (아래 블록 전체를 복사)

```
value-cocreation/01_슬라이드원고.md 를 읽고, 그 내용대로 Figma에 발표 슬라이드를 만들어줘.

[작업 방식]
- figma-use 스킬을 먼저 불러온 뒤 작업해.
- 새 Figma 파일을 만들어줘. 파일명: "AI시대 가치공동창출활동 사례 분석". Figma Slides가 가능하면 Slides로, 아니면 Design 파일에 1920×1080 프레임으로 만들어.
- 프레임은 17개: 표지 1 + 본문 15 + 참고문헌 1. 프레임 이름은 "00_표지", "01_목차" … "15_결론", "16_참고문헌".
- 원고 맨 아래 '디자인 가이드'의 폰트·색·레이아웃·컴포넌트 규칙을 따라.
- 반복 요소(공동창출 순환 다이어그램, 분석 태그 3종, [계획] 점선 배지, 상단 섹션 라벨, 하단 출처·페이지 번호)는 컴포넌트로 먼저 만들고 각 슬라이드에서 인스턴스로 써.
- 각 슬라이드에는 원고의 '제목', '핵심 메시지', '본문', '시각 요소'만 넣고, '발표 메모'는 슬라이드에 넣지 말고 프레임 옆 메모(또는 Slides의 speaker notes)로 넣어.
- 원고에 [원문 확인] 표시가 남아 있으면 해당 텍스트를 주황색(#FF8A00)으로 표시해서 내가 찾기 쉽게 해줘.
- 14번 '나의 생각' 슬라이드의 5번 항목(본인 경험 예시 자리)은 회색 placeholder로 남겨둬.
- 참고문헌 슬라이드에는 AI 프롬프트·응답 캡처를 넣을 빈 이미지 자리 2~3개를 만들어.

[표지 정보]
- 학번: ________  학과: ________  이름: ________

[검수]
- 다 만든 뒤 슬라이드마다 스크린샷을 찍어서 글자 넘침, 겹침, 대비 부족을 확인하고 고쳐.
- 슬라이드당 본문이 6~7줄을 넘으면 핵심만 남기고 나머지는 발표 메모로 옮겨.
- 끝나면 Figma 파일 링크와 수정한 부분 요약을 알려줘.
```

## Figma 작업 후
- Figma Slides: 오른쪽 위 메뉴 → Export → **PDF** 또는 **PPTX**로 내보낸다. 과제는 ppt나 pdf 제출이다.
- 내보낸 뒤 전체 장수를 확인한다(표지·참고문헌 제외 15장 이내).
