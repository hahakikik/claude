# 템플릿 프레임 목록과 시각 언어

> 대상: 「리서치 템플릿_로봇_기업3개.pptx」(46장, 13.33×7.5in). 2026-10-03에 XML을 분석해 정리했다.
> 슬라이드 번호는 원본 템플릿 기준이다. 작업하면서 슬라이드를 넣고 빼면 번호가 바뀌므로, 명령문에서는 번호가 아니라 **프레임 제목**으로 가리킨다.

## 1. PPT Claude에게 알려야 하는 구조 사실

- 모든 슬라이드가 빈(Blank) 레이아웃 위에 도형을 직접 놓아 만든 것이다. 자리표시자가 없다.
- 테마 글꼴(Calibri)과 테마 색(Office 기본)은 실제로 쓰이지 않는다. PPT Claude가 마스터·테마를 읽으면 엉뚱한 글꼴과 색을 고른다. 그래서 명령문에 글꼴과 색을 직접 적는다.
- 새 슬라이드는 비슷한 프레임을 **복제해서** 시작한다. 그래야 상단 바·왼쪽 메뉴 같은 반복 요소가 함께 따라온다.
- 표는 표 개체가 아니라 사각형을 조립한 것이다. 행 수를 바꾸기 어려우면 PowerPoint 표 개체로 새로 만들고 3절의 표 서식을 입힌다.
- 프레임 안의 막대·산점도는 데이터 차트가 아니라 도형이다. 수치 차트는 사용자가 Word에서 붙여 넣은 차트로 바꾼다.
- 쪽번호는 필드가 아니라 그냥 글자다. 직접 고쳐야 한다. 기업 페이지 27~29번은 모두 '23'으로 되어 있다.

## 5. 구성안 장별 추천 프레임 (출발점이고, 장마다 더 맞는 것을 골라도 된다)

| 구성안 | 추천 프레임 | 이유 |
|---|---|---|
| 1장 (1/2) 체급 숫자 + 출하·쓰임새 | 산업 기초 데이터 | 위쪽 숫자 카드가 '체급 숫자 3개' 자리 |
| 1장 (2/2) 돈의 흐름 + 어질리티 차트 | 시장 규모와 성장률 | 차트 1개 + 해석 구조 |
| 2장 가치 4가지 + 가격 조건 차트 | 산업 논리 · 수요 동인 | 동인 카드 = 가치, 결론 박스 = 하단 다리 문장 |
| 3장 감지 → 판단 → 구동 | 기능 지도(원고 그림 1)는 이미지라 고칠 수 없다. 그림 속 글을 옮겨 '다중 입력 → 단일 결과' 골격으로 다시 그린다 | 감지·판단·구동·에너지가 로봇 하나로 모이는 구조 |
| 4장 원인 사슬 + 가동시간 막대 + 체크리스트 | 병목 → 대체 경로 · 개요 | 배터리 병목에서 '자동 교체 / 짧고 잦은 충전'으로 갈라지는 구조와 같다 |
| 5장 (1/2) 실패 횟수 차트 + 확인할 점 | 시장 규모와 성장률 | 차트 + 해석 박스(확인할 점) |
